# my-app (React practice)

A small React app I built while learning React. It is split into components: Header, Content and Footer, with a dark page layout.

## Built with
React, styled-components, Create React App

## Project structure
- `src/App.js`: page layout and styles
- `src/components/Head`: Header component and its CSS
- `src/components/Content`: Content component
- `src/components/Foot`: Footer component

## Run locally
```bash
git clone https://github.com/moh9180812-cyber/my-app.git
cd my-app
npm install
npm start
```
Then open http://localhost:3000.
